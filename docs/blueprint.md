# **App Name**: DocuAsk

## Core Features:

- PDF Upload: Users can upload PDF documents via a drag-and-drop interface or a file selection dialog.
- Question Input: Display a user-friendly interface for asking questions related to the uploaded document. 
- Intelligent Question Answering: Use a Large Language Model to interpret user questions and retrieve relevant information from the uploaded PDF. LLM can act as a tool that reasons whether the question can be answered using the document context. 
- Answer Display: Display the AI-generated answer clearly, with options for follow-up questions.
- Conversation History: Implement a feature to save conversation history for each document.

## Style Guidelines:

- Primary color: Moderate violet (#8074E8) to evoke a sense of intelligence, clarity, and trustworthiness.
- Background color: Light lavender (#F1F0FA) to provide a clean, unobtrusive backdrop that emphasizes content.
- Accent color: Soft pink (#E87480) for highlighting interactive elements and important information.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward feel; body font: 'Inter' (sans-serif) for readability in longer text.
- Use simple, minimalist icons to represent document actions (upload, save, etc.).
- Implement a clean and intuitive layout that prioritizes ease of navigation and content consumption, inspired by the design provided at https://www.figma.com/file/QHpASp7wGRRcjh0oxCuspL/FullStack-Engineer-Internship-Assignment?type=design&node-id=0-1&mode=design&t=geu9rfpXEecN8eFZ-0
- Incorporate subtle animations during PDF processing and question submission to provide user feedback.
